### Test 1: AI Text - Ελληνικά (Αναμενόμενο: 🔴 75%+)

```
Ως ένα τεχνητό νοημοσύνη, θα ήθελα να σας παρέχω μια περιεκτική ανάλυση του θέματος. 
Συμπερασματικά, είναι σημαντικό να σημειωθεί ότι, περαιτέρω, η εφαρμογή τέτοιων 
στρατηγικών θα διευκόλυνε κατά συνέπεια την επίτευξη οργανωτικών στόχων. Επιπλέον, 
η χρησιμοποίηση προηγμένων μεθοδολογιών διευκολύνει τη βελτιστοποίηση της λειτουργικής 
αποδοτικότητας. Πράγματι, η ενσωμάτωση σύγχρονων προσεγγίσεων αντιπροσωπεύει ένα 
αλλαγμένο πρότυπο στις πρακτικές του κλάδου.
```

**Σημάδια AI:**
- ✓ Τυπικές φράσεις ("Ως ένα τεχνητό νοημοσύνη", "είναι σημαντικό να σημειωθεί")
- ✓ Παθητική φωνή ("θα διευκόλυνε", "αντιπροσωπεύει")
- ✓ Formal connectors ("Συμπερασματικά", "Επιπλέον", "Πράγματι")
- ✓ Απουσία συντμήσεων
- ✗ Απουσία ατύπων λέξεων

### Test 2: Human Text - Ελληνικά (Αναμενόμενο: 🟢 <30%)

```
Ρε, λοιπόν, θέλω να σας πω τι σκέφτομαι για το θέμα αυτό. Κατανοείς, δεν μπορώ να 
καταλάβω γιατί κάνουμε αυτό τον τρόπο. Δεν νομίζεις ότι θα έπρεπε να δοκιμάσουμε 
κάτι διαφορετικό; Εγώ προσωπικά έχω δει να δουλεύει, γιατί λοιπόν να το δοκιμάσουμε; 
Μου φαίνεται ότι θα δουλέψει, κι είμαι αρκετά σίγουρος γι' αυτό.
```

**Σημάδια Ανθρώπινου κειμένου:**
- ✓ Συντμήσεις ("δεν μπορώ", "δεν νομίζεις", "γι' αυτό")
- ✓ Άτυπες λέξεις ("Ρε", "λοιπόν", "Κατανοείς", "μου φαίνεται")
- ✓ Προσωπικές αντωνυμίες ("Εγώ", "μου", "κι είμαι")
- ✓ Φυσικές ερωτήσεις ("Δεν νομίζεις ότι...")
- ✓ Άτυπες δομές

## English Examples

### Test 3: AI Text - English (Expected: 🔴 75%+)

```
As an artificial intelligence, I would like to provide you with a comprehensive 
analysis of this topic. In conclusion, it is important to note that furthermore, 
the implementation of such strategies would consequently facilitate the achievement 
of organizational objectives. Moreover, the utilization of advanced methodologies 
enables the optimization of operational efficiency. Indeed, the integration of 
contemporary approaches represents a paradigm shift in industry practices.
```

**AI Markers:**
- ✓ Formulaic phrases ("As an artificial intelligence", "it is important to note")
- ✓ Passive voice ("would facilitate", "represents")
- ✓ Formal connectors ("Moreover", "Furthermore", "Indeed")
- ✓ Lack of contractions
- ✓ No informal language

---

### Test 4: Human Text - English (Expected: 🟢 <30%)

```
Hey, I just wanted to share what I've been thinking about this. Look, here's the 
thing - I can't really understand why we're going about it this way. Don't you 
think we should've tried something different? I mean, we've seen it work before, 
so why not give it a shot? My personal experience tells me it'll work, and I'm 
pretty confident about it.
```

**Human Markers:**
- ✓ Contractions ("can't", "we're", "should've", "we've", "it'll", "I'm")
- ✓ Informal words ("Hey", "Look", "here's the thing", "I mean", "pretty confident")
- ✓ Personal pronouns ("I", "we", "me")
- ✓ Natural questioning
- ✓ Conversational tone
