- **Γιατί**: ο χρήστης ζήτησε αυτόματο background component που να αντλεί νέες
  AI-φράσεις από το internet μέσω Brave, συνεχώς, όταν ανοίγει το run.bat.

  το σκορ ενός εγγράφου δεν αλλάζει ποτέ μόνο του ανάμεσα σε δύο τρεξίματα
  (κρίσιμο για εργαλείο ακαδημαϊκής ακεραιότητας).
- **Αποτέλεσμα πρώτου refresh** (web research, όχι Brave — βλ. παρακάτω γιατί):
  προστέθηκε μόνο **"nuanced"** (EN, weight 1) στο `AI_PHRASES_EN`. Η
  πλειονότητα των "νέων" λέξεων από SEO-λίστες τύπου "300+ AI words to avoid
  2026" ήταν είτε ήδη καλυμμένες (leverage, streamline, robust, pivotal,
  comprehensive, boasts, realm, underscore, navigating the complexities κ.ά.)
  είτε πολύ γενικές/επικίνδυνες για προσθήκη (infrastructure, ecosystem,
  significant, rapid, future, journey, implementation) — θα χτυπούσαν λάθος
  σε κανονικό ακαδημαϊκό/τεχνικό κείμενο (π.χ. μια δικτυακή διπλωματική ΝΟΜΙΜΑ
  χρησιμοποιεί "infrastructure"/"implementation" συνέχεια).
- Επιβεβαίωση εξωτερικής έρευνας: μελέτη του Max Planck Institute (2024)
  βρήκε άνοδο 50%+ στη χρήση λέξεων όπως delve/robust/pivotal σε δημοσιευμένα
  κείμενα μετά την κυκλοφορία του ChatGPT — επιβεβαιώνει ότι τα ήδη υπάρχοντα
  βάρη (delve=3, robust=1, pivotal=2) ήταν σωστά στοχευμένα.
- Δεν βρέθηκε τεκμηριωμένο υλικό ειδικά για ελληνικά AI-tells — καμία νέα
  προσθήκη σε AI_PHRASES_EL αυτόν τον γύρο (καλύτερα καμία προσθήκη παρά
  εφεύρεση χωρίς έρευνα).
- **Ιδέα για το μέλλον, ΟΧΙ υλοποιημένη**: έρευνα ανέδειξε ότι τα πιο αξιόπιστα
  σημερινά AI-tells είναι δομικά, όχι λεξιλογικά — π.χ. πάντα δηλώνει ρητά το
  «συμπέρασμα» αντί να το αφήνει να φανεί, ποτέ δεν απευθύνεται στον αναγνώστη
  σε β' πρόσωπο, «δένει» κάθε νήμα της αφήγησης πολύ τακτοποιημένα. Θα
  χρειαστεί νέος, ξεχωριστός δείκτης (όχι phrase-list) — μεγαλύτερο έργο,
  εκτός scope για ένα απλό refresh.
- Regression check: `python test_detector.py` — όλα περνάνε αναλλοίωτα
  (ίδιος διαχωρισμός AI/human EN 88.6, EL 67.5 — η προσθήκη είναι ουδέτερη

## Τι Βελτιώθηκε

### 1️⃣ Ανίχνευση Γλώσσας (Language Detection)

```python
def detect_language(text: str) -> str:
    """Αυτόματα ανιχνεύει αν το κείμενο είναι στα ελληνικά ή αγγλικά"""
    greek_chars = len(re.findall(r'[α-ωάέήίόύώΑ-ΩΆΈΉΊΌΎΏ]', text))
    english_chars = len(re.findall(r'[a-zA-Z]', text))
    return "greek" if greek_chars > english_chars else "english"
```

✅ **Πλεονέκτημα:** Δεν χρειάζεται να το πείτε - ανιχνεύει μόνο του!

### 2️⃣ Ελληνικά Patterns

Προσθήκη **8 ελληνικών patterns** ειδικά για ελληνικό κείμενο:

| Pattern | Παράδειγμα |
|---------|-----------|
| **Formulaic openings** | "Ως", "Συμπερασματικά", "Τελικά" |
| **Formal connectors** | "Επιπλέον", "Περαιτέρω", "Κατά συνέπεια" |
| **Passive voice** | "είναι γνωστό", "θεωρείται", "αναγνωρίζεται" |
| **Generic statements** | "είναι σημαντικό να σημειωθεί" |
| **Formal buzzwords** | "συνέργεια", "ολιστικό", "παραδείγμα" |
| **Lack of contractions** | "δεν μπορώ", "δεν είναι" |
| **Perfect formatting** | Αριθμημένες παράγραφοι |
| **Repetitive patterns** | Επανάληψη των ίδιων λέξεων |

### 3️⃣ Ελληνικά Human Markers

# Ελληνικές συντμήσεις και άτυπες λέξεις

informal_words = re.findall(r"\b(ε|λοιπόν|δηλαδή|ξέρεις|κατανοείς|τι|πώς)\b", text)

## Παραδείγματα

### Ελληνικό AI Text → 78% 🔴
```
Ως τεχνητή νοημοσύνη, θα ήθελα να σας παρέχω μια 
περιεκτική ανάλυση. Είναι σημαντικό να σημειωθεί ότι 
περαιτέρω η εφαρμογή τέτοιων στρατηγικών θα διευκόλυνε 
κατά συνέπεια την επίτευξη στόχων...
```

❌ **AI Markers ανιχνευθέντα:**
- Formulaic opening: "Ως τεχνητή νοημοσύνη"
- Generic: "Είναι σημαντικό να σημειωθεί"
- Formal connectors: "περαιτέρω", "κατά συνέπεια"
- NO informal words
- NO contractions

---

### Ελληνικό Human Text → 15% 🟢
```
Ρε, θέλω να πω τι σκέφτομαι γι' αυτό. 
Δεν μπορώ να καταλάβω γιατί κάνουμε αυτό τον τρόπο. 
Δεν νομίζεις ότι θα έπρεπε να δοκιμάσουμε 
κάτι διαφορετικό; Έχω δει να δουλεύει...
```

✅ **Human Markers ανιχνευθέντα:**
- Contractions: "γι'", "δεν", "θα έπρεπε"
- Informal words: "Ρε", "θέλω", "δεν μπορώ"
- Personal pronouns: "Έχω", "μου", "κι είμαι"
- Natural questions
